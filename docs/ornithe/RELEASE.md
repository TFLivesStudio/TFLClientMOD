Experimental **TFL Client for Minecraft 1.8.9 / Ornithe Gen2 / Java 25**.

This is an additional platform for the existing shared TFL core. It does not replace Forge.
Seven initial modules: FPS, coordinates, CPS, keystrokes, zoom, toggle sprint and basic crosshair;
shared main menu, settings, HUD editor and preference storage. Right Shift opens settings, V zooms.

Install using the official Ornithe instance creator for Prism Launcher. Required external dependency:
**Ornithe Standard Libraries 0.22.2**. Optional target stack: **Legacy LWJGL3 1.4.10 + Argentum 1.0.2**.
Use Fabric Loader **0.19.5 through Ornithe Gen2**, not a generic Fabric/Gen1 profile. Do not use Forge.
Java **25** is required. External mod JARs, including proprietary Argentum, are not redistributed.

See README.md for installation, exact dependency hashes, build/reproduction commands and portability
roadmap; VALIDATION.md and runtime evidence identify tested scenarios and known limits.

This prerelease contains the installable JAR, sources, complete corresponding repository source,
dependency lock and checksums. Runtime smoke evidence is attached separately. Physical-GPU,
macOS/Windows and broad modpack/server certification remain outside this Linux software-GL experiment.
No performance superiority is claimed. Review remains in a draft PR; do not treat this as stable TFL.
