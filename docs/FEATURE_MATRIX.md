Las limitaciones por versión upstream siguen en `vendor/trs-client/README.md`. Especialmente:
animación 1.7 de golpe al usar no disponible en 26.3; hitbox-color no disponible en 1.21.9+;
colores/postproceso no disponible con backend Vulkan. No se promete funcionamiento basándose solo
en que exista una clase. Los campos `settings` del JSON permiten auditar cada ajuste registrado.

Evidencia adicional de esta candidata: smokes Fabric nativos de menús/mapas, mundo local,
minimapa, waypoints, dimensiones y exportación. El JAR de usuario valida además las operaciones
de configuración desde UI. Esto aumenta la evidencia de los componentes afectados, sin convertir
la lista completa de 79 módulos en una certificación de gameplay. Véase TESTING.md.
